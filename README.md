## Getting started
### Define environment variables:
create a filer at the project root `./.env`
```
PORT=3000
RESEND_API_KEY=<resend api key>
RESEND_FROM_ADDRESS=<from email, defaults to resend development set up = {"Acme <onboarding@resend.dev>"}>
RESEND_FROM_ADDRESS=<to email, defaults to resend development set up = {"delivered@resend.dev"}>
```
